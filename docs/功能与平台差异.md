# location 功能与平台差异

本版源码 Maven `0.1.6` 提供 `location-kuikly` Android、iosArm64、iosX64、iosSimulatorArm64 targets、原生 receiver 和每 Renderer handler。iOS 可选 Pod `GycLocationKuikly/Kuikly` `0.1.6` 使用真实 `OpenKuiklyIOSRender 2.28.0`；Kotlin handler 由宿主已有 Shared framework 导出。发布与远程消费状态以[对应 Release](https://github.com/gycrosskit/location/releases/tag/0.1.6)为准。历史基线 Maven `0.1.5` 的 `-kuikly` 仅含 OHOS 变体；原 HAR 沿用。宿主需注册并维护已有原生能力 owner，示例见[接入指南](接入指南.md#androidios-kuikly-native-module)。


历史发布基线：Maven 0.1.5；HAR 0.1.4。源码基线：`817926f52594a9501c90ec29e22b501b13b0dc58`，叠加本次修复；最终源码由不可变Git标签`0.1.5`定位。构建、checksum及各渠道实际验收结果见[版本发布记录](https://github.com/gycrosskit/location/releases/tag/0.1.5)，源码/替身测试范围见本页验证表；不声明真实设备业务验收通过。

## 产物与职责

| 模块/产品 | 实际职责 |
|---|---|
| `location-core` | LocationClient.currentLocation、LocationOptions/LocationFix/LocationResult；A LocationManager、i CoreLocation；JVM/OHOS core变体不自带定位实现。 |
| `location-kuikly` | LocationModule 调用侧、AndroidLocationModule / IosLocationModuleHandler 接收端，连接 GycLocationModule；无地图 UI。 |
| `@gycrosskit/location-native` | API22 HAR，LocationClient及GycLocationModule，geoLocationManager。无Swift Package。 |

构建边界：[core构建](../location-core/build.gradle.kts)、[Kuikly构建](../location-kuikly/build.gradle.kts)、[模块清单](../settings.gradle.kts)、[OHOS SDK配置](../ohos/build-profile.json5)。

除上表明确的 UI 入口外，本库没有独立 CMP 页面模块。CMP 直接注入 core；Kuikly Android/iOS 使用候选原生 receiver，宿主只装配能力 owner 与注册入口。库不自动注册 Renderer，也不提供品牌验收。

## 五入口功能矩阵

“原生实现，宿主注入”表示平台能力已有源码，CMP/Kuikly由宿主适配接入；“OHOS Module已实现”表示已有Kotlin/ArkTS调用链。矩阵说明功能接入边界，实际行为验证见下方验证范围。

| 功能/API组 | CMP Android | CMP iOS | Kuikly Android | Kuikly iOS | Kuikly OHOS |
|---|---|---|---|---|---|
| currentLocation / 合格缓存 | 原生实现，宿主注入 | 原生实现，宿主注入 | Native Module源码，须注册 | Native Module源码，须注册 | OHOS Module已实现 |
| 精度/时效/期限过滤 | 原生实现，宿主注入 | 原生实现，宿主注入 | Native Module源码，须注册 | Native Module源码，须注册 | OHOS Module已实现 |
| 权限缺失/服务关闭/超时分类 | 原生实现，宿主注入 | 原生实现，宿主注入 | Native Module源码，须注册 | Native Module源码，须注册 | OHOS Module已实现 |
| 取消/独立listener与旧回执 | 原生实现，宿主注入 | 原生实现，宿主注入 | Native Module源码，须注册 | Native Module源码，须注册 | OHOS Module已实现 |
| 权限申请/地址/坐标转换 | 宿主职责 | 宿主职责 | 宿主职责 | 宿主职责 | 宿主职责 |

## 公开 API 组

- `LocationClient.currentLocation(options=LocationOptions())`：Available(fix)/PermissionMissing/ServiceDisabled/TimedOut/Unavailable。
- `LocationOptions.accepts(fix,nowMillis)`统一经纬/accuracy/timestamp验收；Kotlin取消保留CancellationException。
- OHOS `LocationModule` 连接原生client，页面退出`dispose()`；不提供权限申请或地图UI。

## API 合同与差异分类

| 分类 | 具体输入 / OS / SDK边界 | 调用方应如何处理 |
|---|---|---|
| 组件边界 | 默认timeoutMillis12000、maxAgeMillis300000、maxAccuracyMeters500；阈值端点包含。 | timeout在1..Int.MAX_VALUE，age非负、accuracy有限非负；无效/未来时间、经纬范围/超精度拒绝，输出Unix毫秒原始系统坐标。 |
| 厂商限制 | A LocationManager先筛lastKnown，O先getLastLocation；i CoreLocation更新流在期限内等待合格fix，终态stopUpdatingLocation。 | 不能保证每次缓存命中；O无cache错误继续监听。i kCLErrorDomain/locationUnknown暂时错误继续等，不直接Unavailable，权限/服务变化优先分类。 |
| 宿主职责 | 必须先申请前台位置权限；A粗略权限只使用允许provider；iOS14+；Android API24+；OHOS目标/兼容API22。 | 本库不弹权限框、不提供后台跟踪、逆地理编码、地图或厂商坐标系转换。 |
| 组件边界 | 取消传播CancellationException，不作为LocationResult失败枚举。 | 每次请求独立listener/timer/finish，终态释放自己的订阅；Module watchdog按请求期限加回执余量，非固定提前截断。 |
| 未验收 | 真实定位、定位缓存命中率、不同品牌设备/服务商位置精度。 | 未触发真实定位业务；定向错误分类和mock通过不证明硬件体验。 |

本轮 `0.1.6` Native Module 候选新增 [`LocationModuleHandlerTest`](../verification-kuikly/src/test/kotlin/LocationModuleHandlerTest.kt)：执行生产 handler，JSON/Kuikly transport 为验证替身，检查请求 ID 取消、共享 owner、销毁后的旧结果隔离及状态/非法输入。本轮独立 JVM 检查共 10 例通过，零失败/跳过；Android release 与 iOS Simulator Kotlin 编译通过。真实 OpenKuiklyIOSRender 2.28.0 的 Pod source 构建与 Simulator receiver 生命周期检查通过，覆盖 typed SDK 调用、重复失效、Main 排队调用、工厂创建竞态、Context 排队回调隔离与 SDK dealloc；handler 为受控闭包，未调用权限/相册/定位业务。源码门禁及复现命令见[开发与验证](开发与验证.md)。以上为本轮源码验证，不代替远程消费或真机业务验收；发布状态以对应 Release 为准。
