# location 完整源码审查

2026-10-05，本轮逐文件读取自有生产 Kotlin、Swift、ArkTS、原生桥/导出与 manifest，并追踪公开调用链。审查覆盖 API 合同、状态归属、线程、最低系统、错误分类、取消/销毁与迟到回调；不以热点抽查替代完整文件清单。

## 结论与修改

iOS 等待期间 CoreLocation Restricted 与 Denied 均归 PermissionMissing，服务关闭与其他失败分类保持。HAR 时效检查新增 timestampMillis >= 0，防止宿主使用很大 maxAgeMillis 时把负时间戳误接收/缓存，与 KMP 合同一致。

## 最低系统与线程

Android：API24+；iOS：iOS14+；OHOS：实际 target/compatible API22。Android LocationManager 与 iOS CLLocationManager 的等待/清理切 Main；HAR 使用单次 request、timer、异步权限/服务查询与原生 listener 归属。

## 公开调用链

- LocationOptions / LocationResult → Android GPS/NETWORK provider listener → 时效/精度过滤、timeout 和 finally 解绑。
- IosLocationClient → 每次独占 CLLocationManager / delegate → locationFailure 分类 → Main stop/delegate 清理。
- LocationModule → GycLocationModule → HAR LocationClient → geoLocationManager、内存缓存、timer 和 cancel；Index 导出 options/fix/result/request。
