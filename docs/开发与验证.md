## 环境与检查

源码构建使用 JDK 17、Gradle wrapper、Android SDK（compileSdk 36）；iOS 需要 macOS/Xcode，HarmonyOS HAR 需要匹配 API 22 的 DevEco SDK、ohpm 与 hvigorw。先配置 `ANDROID_HOME` 和 HarmonyOS 工具链路径，命令从仓库根目录运行；以下是维护者检查命令，不是第三方安装步骤。

```sh
bash gradlew :location-core:jvmTest :location-core:compileDebugKotlinAndroid :location-core:compileKotlinIosSimulatorArm64
node ohos/tests/location.test.cjs
bash gradlew -p verification-consumer compileDebugKotlinAndroid compileKotlinJvm compileKotlinOhosArm64 compileKotlinIosArm64 compileKotlinIosX64 linkDebugFrameworkIosSimulatorArm64 -PlocationVersion=0.1.2 --max-workers=1 --no-parallel
```

HAR 契约检查可用 `TYPESCRIPT_PATH` 指向已有 TypeScript 模块。

HarmonyOS HAR 在 `ohos/` 内执行：

```sh
ohpm install --all
hvigorw --mode module -p module=LocationNative@default -p product=default assembleHar --no-daemon
```

需要 SDK 的检查只在对应环境执行；不默认 `clean` 或全仓库构建。独立消费者使用 README 的远程 Maven 坐标，不使用 `mavenLocal` 或源码 `project/includeBuild` 替换。

## 已有验收与限制

[0.1.0 Release](https://github.com/gycrosskit/location/releases/tag/0.1.0) 记录公共边界 JVM 测试、HAR 编译、取消/超时/缓存契约检查与远程 Maven 消费。JVM 测试覆盖时间、精度和经纬度边界；HAR 检查覆盖权限、服务、取消幂等、超时、陈旧/精度不合格位置与缓存。本轮文档修改没有重跑这些检查。

2026-09-30 文档核对：Maven `0.1.0` 的根 artifact POM 可从 JitPack 读取，JitPack 构建状态 `ok`；[OHPM registry](https://ohpm.openharmony.cn/ohpm/@gycrosskit%2Flocation-native) 的 versions/latest 包含 `0.1.0`。这只是当前远程元数据/文档核对，未执行新的安装、构建或设备测试。旧 Release 中“审核中/404”描述是当时状态，现行安装版本以 README 和 registry 为准。

编译、链接、契约测试和远程 metadata 不代表真实设备验收。系统权限弹窗、相机或定位能力、系统页面、前后台生命周期、多窗口和内存边界需按本库实际能力在宿主设备检查。

## Maven 产物维护

Maven Android/iOS/OHOS（按本库实际 target）产物在 macOS 生成并放入版本化 Release 归档；JitPack 下载对应不可变标签的归档，校验 SHA-256 后安装。源码检查不能替代完整 KMP `.module` 与每个引用产物的检查；本地 Maven 验证不能替代默认远程消费。标签、归档与校验和不得覆盖，Maven 二进制不提交到源码仓库。

完整发布步骤与不可变产物约束见 [GY CrossKit 发布流程](https://github.com/gycrosskit/.github/blob/main/docs/发布流程.md)，历史版本见 [发行页](https://github.com/gycrosskit/location/releases)。

## 0.1.2 发布前源码复核

Kuikly 原生定位按 LocationOptions.timeoutMillis 结算；桥接 watchdog 等待 `max(bridgeTimeoutMillis, timeoutMillis + 2000)` 毫秒。原构造参数/命名保留，但作为桥接最短等待，不再截断更长请求。既有请求 10 秒/bridge 12 秒的组合不变。watchdog 到期返回 TimedOut；原生空/错误回执仍是 Unavailable，外部取消继续传播并取消所属请求。
独立检查：`bash gradlew -p verification-kuikly test`，真实 LocationModule 使用虚拟时间覆盖 30 秒请求、默认回执余量、旧 10/12 组合、空回执和迟恢复销毁。审阅清单、命令结果在 `build/remote-library-review/coverage.json`；本节源码已随 0.1.2 prerelease 发布，远程消费结果见本轮发布验收。

metadata、installer 与严格 checker 同步组织模板；`python3 scripts/test-jitpack-metadata.py` 验证来源/资源变体裁剪与 hash 刷新，`python3 scripts/test-check-maven.py` 验证完整发布及 8 类损坏制品。归档时额外核验 JAR/AAR/KLIB/ZIP 的 CRC。本轮归档和真实远程消费已完成，结果见 [0.1.2 发布验收](发布验收-0.1.2.md)；既有版本验收只对应其不可变字节。
