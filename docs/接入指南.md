## Gradle 与工具链

根 README 列出远程安装坐标。本库 KMP 产物使用 Kotlin `2.2.21-1.0.0`；OHOS target 必须使用兼容的厂商工具链。项目构建使用 Gradle `8.11.1`、AGP `8.10.1`、Android compileSdk `36`，Gradle 运行使用 JDK 17。源码的 Java/JVM 编译目标与运行 Gradle 的 JDK 是不同要求。

## Android / iOS

Android 创建 `AndroidLocationClient(context)`，iOS 创建 `IosLocationClient()`，公共入口 `LocationClient.currentLocation(options)`。Android 同时监听已启用 GPS/网络 Provider，接收第一份合格位置；iOS 每次请求独占 CLLocationManager/delegate，平台操作内部切主线程。

Android Manifest 按需声明 `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION`；iOS Info.plist 填写 `NSLocationWhenInUseUsageDescription`。调用前由宿主主动取得权限。库不把粗略授权直接判失败，只有位置满足精度才成功；无需背景授权。

`LocationOptions` 默认超时 12 秒、最大缓存年龄 300 秒、最大误差 500 米；`timeoutMillis` 在 `1..Int.MAX_VALUE`，`maxAgeMillis` 非负，`maxAccuracyMeters` 为有限非负值。坐标保持系统原始坐标系，Unix 毫秒时间；非法经纬度、未来/过期坐标、负值或超标精度拒绝。业务需要严格精度时自行设置。

请求协程与页面生命周期绑定。完成、超时和取消都清理系统监听；外部取消继续传播，不转换为普通失败。无合格位置返回 `TimedOut`，系统错误可能返回 `Unavailable`。

## HarmonyOS 原生

OHPM 安装见 README。原生 ArkTS 入口不变；0.1.1 候选同时提供 Kotlin/Kuikly 桥：

```typescript
import { LocationClient, LocationOptions } from '@gycrosskit/location-native';
const client = new LocationClient();
const options = new LocationOptions();
options.maxAccuracyMeters = 100;
const request = client.currentLocation(options);
// 将 request 保存到页面；页面销毁时调用 request.cancel()。
const result = await request.result;
```

在 `module.json5` 声明并由宿主申请 `ohos.permission.APPROXIMATELY_LOCATION`；精确定位另加 `ohos.permission.LOCATION`。`status` 为 `available / permission_missing / service_disabled / timed_out / unavailable / cancelled`；成功的 `fix` 含纬度、经度、精度、Unix 毫秒时间。取消结果为 `cancelled`，重复 cancel 幂等。

每个 client 只在内存缓存上次成功位置；读取缓存时仍重新检查权限、服务、时效、精度，不持久化坐标。页面生命周期由宿主管理，本库不启动后台服务或持续监听。

平台参考：[Android LocationManager](https://developer.android.com/reference/android/location/LocationManager)、[Apple CoreLocation](https://developer.apple.com/documentation/corelocation)、[OpenHarmony LocationKit](https://gitee.com/openharmony/docs/blob/master/zh-cn/application-dev/reference/apis-location-kit/js-apis-geoLocationManager.md)。

取消接线：GycLocationModule 在 cancelLocation 命中 requestId 时同步撤销 active/id，再停止原生 listener；
下一请求可在同一调用批次立即开始，不等待旧 Promise microtask。旧结果不再回调。
Kotlin await 完成后再检查 disposed，阻止已 resume 但尚未交付的 Available 在页面销毁后返回。

未发布源码的桥接 watchdog 按请求期限加 2 秒回执余量，且不短于 bridgeTimeoutMillis；到期返回 TimedOut，原生空回执仍为 Unavailable。当前 10 秒定位/12 秒 bridge 参数不变。
